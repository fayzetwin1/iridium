# Как подключить свой Apple Music к Iridium (Windows)

Вам не нужно ставить Python или скачивать исходники бота. Понадобятся установленный Microsoft Edge, действующая подписка Apple Music и доступ к боту Iridium.

1. Скачайте `IridiumCookieExport-Windows.zip` из [последнего релиза](https://github.com/fayzetwin1/iridium/releases/latest) и распакуйте архив в отдельную папку.
2. Запустите `IridiumCookieExport.exe`. Откроется отдельное окно Edge на `music.apple.com`.
3. Войдите в **свой** Apple-аккаунт и завершите двухфакторную проверку. Скрипт сохранит `cookies.txt` рядом с `.exe`. Если файл уже есть, он не будет перезаписан: удалите старый файл или запустите программу с `--replace` из терминала.
4. Откройте личный чат с Iridium, нажмите `/start` → «Сессия» → «Подключить / обновить». Отправьте `cookies.txt` **как документ** в течение 10 минут.
5. После сообщения об успешном подключении удалите локальный `cookies.txt`, если он больше не нужен. В боте можно удалить загруженную сессию через раздел «Сессия».

`cookies.txt` даёт доступ к музыкальной сессии. Не публикуйте его и не отправляйте никому, кроме выбранного вами бота. Скрипт сохраняет только cookie `media-user-token` локально; он не отправляет файл автоматически. Владелец сервера бота сможет прочитать загруженную сессию.

Если вместо Edge нужен установленный Chrome, запустите `IridiumCookieExport.exe --browser chrome` в PowerShell. Если вход не завершился за 10 минут, запустите программу заново с `--timeout 1200`.
