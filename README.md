# Iridium — личный Telegram-бот для Apple Music

Iridium на aiogram 3.x принимает ссылку на песню или плейлист Apple Music, либо текстовый запрос. Для найденного трека доступен AAC (.m4a); для владельца бота можно отдельно включить ALAC lossless. Бот отвечает только Telegram ID из списка доступа и использует отдельную сессию Apple Music для каждого пользователя.

Для загрузки используется неофициальный [gamdl](https://github.com/glomatico/gamdl). Его работоспособность зависит от Apple Music, действующей подписки и текущей версии gamdl. Условия Apple могут ограничивать такое использование.

Код разбит на пакет `iridium_bot`: `settings.py` читает настройки, `catalog.py` работает с каталогом Apple Music, `downloader.py` запускает gamdl и проверяет файл, `telegram.py` содержит вызовы Bot API, `app.py` обрабатывает команды и inline-запросы. `music_bot.py` оставлен для совместимости с прежней командой запуска.

## Установка на Windows

1. Установите Python 3.11 или новее, FFmpeg (нужен `ffprobe`) и создайте бота через @BotFather. В текущем окружении установка проверена с Python 3.14. Выполните `ffprobe -version` в PowerShell.
2. В каталоге проекта создайте окружение и установите зависимости:

   ```powershell
   py -3.14 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -e .
   ```

3. Создайте `cookies.txt` через локальный помощник ниже или экспортируйте cookies вручную в формате Netscape по [инструкции gamdl](https://github.com/glomatico/gamdl/blob/main/README.md#prerequisites). Не публикуйте этот файл.
4. Скопируйте `.env.example` в `.env`. Укажите токен бота, свой числовой Telegram ID и абсолютный путь к cookies. Других пользователей перечислите через запятую в `TELEGRAM_USER_IDS`. Числовой ID можно получить из Telegram Bot API `getUpdates` после сообщения своему боту; сам токен держите в секрете.
5. Запустите:

   ```powershell
   .\.venv\Scripts\python.exe -m iridium_bot
   ```

При первом запуске `ENABLE_ALAC=false`, поэтому кнопки ALAC не показываются. Отправьте боту название песни, ссылку вида `https://music.apple.com/.../song/...` или `/playlists`. Ссылка на альбом с `?i=<id>` тоже распознаётся как отдельный трек. Из плейлиста бот показывает треки для выбора; за один запрос скачивается только выбранная песня.

Команда `/start` открывает меню Iridium: поиск, плейлисты, управление сессией, справка и сведения о проекте. Основные кнопки используют стили Telegram `primary` и `success`; удаление сессии — `danger` с подтверждением. В разделе «О проекте» указаны [GitHub-репозиторий](https://github.com/fayzetwin1/iridium) и [канал автора](https://t.me/fayzetwintop). Их можно переопределить через `PROJECT_GITHUB_URL`, `PROJECT_CREATOR` и `PROJECT_CREATOR_URL` в `.env`. Если URL оставить пустым, соответствующая кнопка не показывается. Отображение цветов зависит от версии клиента Telegram и выбранной темы.

## Поиск из любого чата (inline)

В @BotFather включите inline-режим командой `/setinline` для этого бота. Затем в любом чате введите `@имя_бота название трека` или `@имя_бота https://music.apple.com/.../song/...` и выберите найденный трек. Поиск по названию идёт по всему каталогу Apple Music, а не по личному плейлисту. Ссылка на плейлист отдельно покажет первые 10 треков.

Если AAC трека уже загружали после текущего запуска бота, выбор результата сразу отправляет аудио в чат. Для нового трека сначала появится карточка с кнопкой «Загрузить AAC в этот чат»: бот скачает файл, временно загрузит его в личный чат пользователя для получения Telegram `file_id`, удалит временное сообщение и заменит карточку аудио в исходном чате. Это требует, чтобы пользователь уже начал личный чат с ботом. Telegram не позволяет прикрепить новый локальный файл непосредственно к inline-ответу. При `ENABLE_ALAC=true` у владельца остаётся отдельная кнопка ALAC для загрузки в личном чате.

Поиск доступен только пользователям из списка доступа с подключённой сессией. Кнопка загрузки привязана к тому, кто искал трек, и действует 30 минут после поиска; после перезапуска бота повторите поиск. Кэш аудио хранится только в памяти и очищается при перезапуске.

## Автоматический экспорт cookies

Этот помощник запускается **на компьютере владельца Apple-аккаунта**. Он открывает чистое окно Edge на `music.apple.com`, ждёт, пока вы сами завершите вход и 2FA, и сохраняет только `media-user-token` в `cookies.txt` для gamdl. Скрипт не читает уже открытые профили, не спрашивает пароль и не загружает cookie в бот или на сторонний сервер. [Playwright предупреждает](https://playwright.dev/python/docs/auth), что файл с авторизованной сессией следует хранить как секрет.

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[cookie-export]"
.\.venv\Scripts\python.exe -m cookie_export
```

На Windows по умолчанию откроется установленный Edge. Если нужен Chrome, используйте `--browser chrome`. Для Chromium сначала выполните `.\.venv\Scripts\python.exe -m playwright install chromium`, затем запустите помощник с `--browser chromium`. Если `cookies.txt` уже существует, скрипт откажется его заменять; для обновления сессии добавьте `--replace`. Можно выбрать другое расположение через `--output C:/path/to/cookies.txt` и указать этот путь в `.env`.

`wrapper-v2` не использует этот файл: он выполняет собственную авторизацию для ALAC. Помощник предназначен для cookie-режима gamdl, включая AAC.

## Подключение друзей

1. Добавьте Telegram ID друзей в `TELEGRAM_USER_IDS` в `.env` и перезапустите бота. Без записи в списке бот игнорирует их сообщения.
2. Каждый друг запускает `cookie_export` **на своём компьютере** и входит в свой Apple Music аккаунт. Скрипт создаст его личный `cookies.txt`.
3. Друг отправляет боту `/connect`, затем свой файл `cookies.txt` документом в личном чате в течение 10 минут. Бот проверяет подписку, сохраняет только `media-user-token` в `SESSION_DIR/<telegram_id>.cookies.txt` и пытается удалить сообщение с исходным файлом. Удаление сообщения не гарантирует, что Telegram не сохранил файл на своей стороне.
4. `/disconnect` удаляет сохранённый файл с сервера бота. Для владельца также действует путь `APPLE_MUSIC_COOKIES_PATH` из `.env`, пока его не убрать вручную.

Файл cookie фактически даёт доступ к музыкальной сессии. Владелец сервера может прочитать сохранённые файлы; подключайте только тех, кто понимает это. Автоматического входа по ссылке через Apple без Developer Program этот вариант не делает. ALAC для друзей пока отключён: отдельная сессия cookie не переключает аккаунт в общем `wrapper-v2`.

## ALAC lossless

По [документации gamdl](https://github.com/glomatico/gamdl/blob/main/README.md#optional-dependencies), для ALAC рекомендуется [wrapper-v2](https://github.com/glomatico/wrapper-v2). Его нужно подготовить и авторизовать отдельно: он использует Docker и библиотеки Apple Music для Android, которые проект не поставляет. Не выставляйте его HTTP и TCP порты в интернет. После успешной проверки `/health` включите `ENABLE_ALAC=true` в `.env`. Бот не запрашивает пароль Apple ID в Telegram и запускает gamdl без интерактивного ввода.

ALAC отправляется как документ, AAC — как аудиофайл с музыкальным плеером. Перед отправкой `ffprobe` проверяет фактический кодек, поэтому бот не подменит ALAC на AAC молча. Обычный Telegram Bot API принимает файлы до 50 МБ. Если ALAC больше, бот сообщит об ограничении и предложит AAC. [Локальный Bot API](https://core.telegram.org/bots/api#using-a-local-bot-api-server) с лимитом 2000 МБ пока не подключён.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Автоматические тесты не используют подписку и не скачивают музыку. Перед обычным использованием проверьте вручную один трек по ссылке, поиску и из плейлиста; затем сравните полученный в Telegram файл с локальным оригиналом. Запуск без учётных данных Apple и токена Telegram проверить сквозным тестом нельзя.
